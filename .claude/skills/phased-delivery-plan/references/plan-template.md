# Progressive Plan Template

Use this template for each unit.

```markdown
## Unit N: `<type>/<kebab-name>`

### Step Objective

- Implementation goal:
- Learning/operational goal:

### Prerequisite

- [ ] Previous unit merged
- [ ] Required docs reviewed

### References

- [doc link 1]
- [doc link 2]

### Progressive Tasks

1. Task block A
2. Task block B
3. Task block C

### Exit Criteria

- [ ] Verifiable condition 1
- [ ] Verifiable condition 2
- [ ] Verifiable condition 3

### Evidence

- Command logs:
- Artifacts:
- Notes:

### Output for Next Step

- Output 1
- Output 2

### Optional (only if needed)

- Troubleshooting:
- Parameters:
```

## Stage-Level Gate Template

```markdown
## Stage Gate (Final)

### Entry Criteria

- [ ] Scope and references fixed

### Exit Criteria

- [ ] All units satisfy their Exit Criteria
- [ ] All evidence captured
- [ ] Next stage risks documented

### Evidence

- Consolidated command result summary
- Final artifact checklist
- Open risks list
```
