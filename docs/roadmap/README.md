# Learning Roadmap

이 디렉토리는 `docs/harness`의 구현 기준을 학습 가능한 순서로 재배치한 실행 로드맵이다.

## 시작 방법

1. [00-roadmap-overview](./00-roadmap-overview.md)에서 전체 흐름 확인
2. 아래 순서를 그대로 따라 진행
3. 각 문서의 `Exit Criteria`와 `Evidence`를 남기고 다음 단계로 이동

## 문서 순서

1. [00-roadmap-overview](./00-roadmap-overview.md)
2. [01-db-design-and-migrations](./01-db-design-and-migrations.md)
3. [02-authentication-and-authorization](./02-authentication-and-authorization.md)
4. [02a-commerce-core-implementation](./02a-commerce-core-implementation.md)
5. [03-infra-foundation-and-networking](./03-infra-foundation-and-networking.md)
6. [04-docker-build-and-runtime](./04-docker-build-and-runtime.md)
7. [05-kubernetes-deploy-and-release](./05-kubernetes-deploy-and-release.md)
8. [06-observability-and-reliability](./06-observability-and-reliability.md)
9. [07-admin-and-operations](./07-admin-and-operations.md)

로컬 환경 설정은 `01`~`07` 각 문서의 `Local Environment Increment`에 단계적으로 반영되어 있다.
