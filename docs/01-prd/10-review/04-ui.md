# Review UI Guide

## 1) UX 정책 (PRD §7 원문)

- 리뷰 영역은 실구매 여부 배지(예: `verified_purchase`) 표시
- 리뷰 제목은 최대 100자, 본문은 최대 2,000자까지 입력 가능하며 초과 시 입력 차단
- 댓글 본문은 최대 500자까지 입력 가능

## 2) store 리뷰 목록/작성 화면

- `GET /products/:id/reviews`에서 리뷰 목록/요약 조회
- 배송 완료 주문의 구매자만 리뷰 작성 허용
- 사용자당 `order_item` 기준 리뷰 1개(수정은 허용, 중복 생성 금지)
- 평점 범위: `1..5` (별점 선택 UI)
- `hidden`·`flagged` 상태 리뷰는 고객 목록에서 비노출

## 3) admin 모더레이션 화면

- 리뷰 상태(`visible|hidden|flagged`) 필터링 지원
- 부적절 콘텐츠는 운영자가 숨김 처리 후 사유 기록
- 숨김/삭제 권한: `operator|admin`
- 댓글 삭제는 soft delete를 기본으로 하고 감사 로그를 남김
- 리뷰 댓글/리뷰 숨김(모더레이션) 운영 기능
