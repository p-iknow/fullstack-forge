# Review UI Guide

## 1) UX 정책 (PRD §7 원문)

- 리뷰 영역은 실구매 여부 배지(예: `verified_purchase`) 표시
- 리뷰 제목은 최대 100자, 본문은 최대 2,000자까지 입력 가능하며 초과 시 입력 차단
- 댓글 본문은 최대 500자까지 입력 가능

## 2) store 리뷰 목록/작성 화면

- `GET /products/:id/reviews`에서 리뷰 목록/요약 조회
- 배송 완료 주문의 구매자만 리뷰 작성 허용
- 사용자당 `order_item` 기준 리뷰 1개(수정은 허용, 중복 생성 금지)
- 평점 범위: `1..5` (별점 선택 UI)
- `hidden`·`flagged` 상태 리뷰는 고객 목록에서 비노출

### 리뷰 이미지 (store)

- **작성 화면**: 이미지 첨부 영역 제공 (최대 5장)
  - 파일 선택 또는 드래그 앤 드롭으로 업로드
  - 업로드 전 클라이언트 측 포맷(JPEG/PNG/WebP) 및 크기(5 MB) 사전 검증
  - 업로드 중 프로그레스 바 표시
  - 업로드 완료 시 썸네일 미리보기 표시 + 순서 드래그 재정렬 + 개별 삭제 버튼
  - 5장 초과 선택 시 초과분 차단 + 안내 메시지 표시
- **목록 화면**: 리뷰 카드에 첫 번째 이미지 썸네일(`thumb_url`) 표시, 이미지 수 배지
- **상세/갤러리**: 이미지 클릭 시 라이트박스 갤러리로 `detail_url` 확대 표시, 좌우 스와이프 탐색

## 3) admin 모더레이션 화면

- 리뷰 상태(`visible|hidden|flagged`) 필터링 지원
- 부적절 콘텐츠는 운영자가 숨김 처리 후 사유 기록
- 숨김/삭제 권한: `operator|admin`
- 댓글 삭제는 soft delete를 기본으로 하고 감사 로그를 남김
- 리뷰 댓글/리뷰 숨김(모더레이션) 운영 기능

### 리뷰 이미지 (admin)

- 모더레이션 리뷰 상세 화면에서 첨부 이미지 전체 목록 확인 가능
- 이미지 클릭 시 `detail_url`로 확대 확인
- 운영자는 개별 이미지를 직접 삭제하지 않으며, 리뷰 숨김(`hidden`) 처리로 이미지 포함 전체 비노출
