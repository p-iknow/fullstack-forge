# Cart UI Guide

## 1) 목적

- store 장바구니 화면의 기본 구성과 상호작용을 정의한다.
- Stage 2 Exit Criteria의 "store에서 상품 탐색/장바구니 동작" 충족을 위한 최소 UI 요구사항을 명시한다.

## 2) 화면 구성

- 장바구니 항목 리스트: 상품명, 옵션/단위, 수량, 금액, 삭제 액션
- 요약 영역: 총 상품금액, 예상 결제금액, 주문 진행 버튼
- 빈 상태: 장바구니 비어 있음 안내와 상품 탐색 이동 액션

## 3) 수량 조절 동작

- 수량 증가/감소 버튼 제공
- 직접 입력 변경 시 유효성 검증 후 반영
- 정책 최대 수량 초과 시 즉시 에러 메시지 노출
- 수량 0 입력은 허용하지 않고 항목 삭제 흐름으로 유도

## 4) 만료 안내

- 장바구니 만료 예정 시간 표시
- 만료 임박 시 배지 또는 경고 문구 노출
- 만료 발생 시 항목 비활성화 및 재고 해제 안내 문구 노출

## 5) 장바구니 상태별 UI 처리

- `active`: 기본 동작. 항목 추가/수정/삭제 및 주문 진행 허용.
- `converted`: 주문 전환 완료 안내 표시. 항목 변경 불가. 주문 내역으로 이동 유도.
- `expired`: 만료 안내 표시. 항목 비활성화. 새 장바구니 생성 유도.

## 6) 연계 화면

- 상품 상세/목록의 장바구니 추가 액션과 상태 동기화
- 주문서 진입 전 최신 장바구니 상태 재검증
