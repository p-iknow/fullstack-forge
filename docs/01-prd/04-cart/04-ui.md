# Cart UI Guide

## 1) 목적

- store 장바구니 화면의 기본 구성과 상호작용을 정의한다.
- Stage 2 Exit Criteria의 "store에서 상품 탐색/장바구니 동작" 충족을 위한 최소 UI 요구사항을 명시한다.

## 2) 화면 구성

- 장바구니 항목 리스트: 상품명, 옵션/단위, 수량, 금액, 삭제 액션
- 요약 영역: 총 상품금액, 예상 결제금액, 주문 진행 버튼
- 빈 상태: 장바구니 비어 있음 안내와 상품 탐색 이동 액션

## 3) 수량 조절 동작

- 수량 증가/감소 버튼 제공
- 직접 입력 변경 시 유효성 검증 후 반영
- 정책 최대 수량 초과 시 즉시 에러 메시지 노출
- 수량 0 입력은 허용하지 않고 항목 삭제 흐름으로 유도

## 4) 만료 안내

- 장바구니 만료 예정 시간 표시
- 만료 임박 시 배지 또는 경고 문구 노출
- 만료 발생 시 항목 비활성화 및 안내 문구 노출

## 5) 품절 상품 표시

- 품절(`out_of_stock`) 항목은 시각적으로 구분(흐림 처리 + 품절 배지)하여 표시한다.
- 품절 항목의 수량 조절 버튼은 비활성화한다.
- 품절 항목이 1개 이상 존재하면 주문 진행 버튼을 비활성화하고, "품절 상품을 제거해 주세요" 안내를 노출한다.
- 저재고(`low_stock`) 항목은 "재고 부족" 배지를 표시하되 주문 진행은 허용한다.

## 6) 장바구니 상태별 UI 처리

- `active`: 기본 동작. 항목 추가/수정/삭제 및 주문 진행 허용.
- `converted`: 주문 전환 완료 안내 표시. 항목 변경 불가. 주문 내역으로 이동 유도.
- `expired`: 만료 안내 표시. 항목 비활성화. 새 장바구니 생성 유도.

## 7) 로딩 및 에러 상태

### 로딩 상태

- 장바구니 조회 중: 스켈레톤 UI 표시 (항목 리스트 + 요약 영역)
- 수량 변경/삭제 요청 중: 해당 항목에 인라인 스피너 표시, 중복 요청 방지를 위해 버튼 비활성화
- 주문 전환 요청 중: 주문 진행 버튼 로딩 상태 + 전체 항목 수정 차단

### 에러 상태

- API 호출 실패 시: 토스트 알림으로 에러 메시지 노출, 재시도 유도
- 수량 정책 위반 시: 해당 항목 인라인 에러 메시지 (예: "최대 15개까지 담을 수 있어요")
- 동시성 충돌 시(`409`): 장바구니를 최신 상태로 자동 새로고침 후 변경 사항 안내
- 주문 전환 실패 시: 에러 토스트 + 장바구니 상태 유지 (재시도 가능)

## 8) 확인 다이얼로그

- 장바구니 전체 비우기(`DELETE /api/store/cart`): 확인 다이얼로그 필수 ("장바구니를 비우시겠습니까?")
- 단일 항목 삭제: 확인 다이얼로그 없이 즉시 삭제 (실수 시 재추가 가능)

## 9) 가격 변경 고지

- 주문 전환 시 가격 차이가 감지되면 변경된 항목과 금액 차이를 모달로 표시한다.
- 사용자 확인 후 주문을 진행하거나 장바구니로 돌아갈 수 있다.

## 10) 연계 화면

- 상품 상세/목록의 장바구니 추가 액션과 상태 동기화
- 주문서 진입 전 최신 장바구니 상태 재검증
