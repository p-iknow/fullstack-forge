# Payment UI

## 대상 화면

- Store 결제 진입/진행/완료 화면
- Store 결제 실패 안내 화면

## Store 결제 진입 화면

- 주문 요약과 최종 결제 금액을 확인하고 결제를 시작한다.
- 결제 시작 시 중복 클릭 방지 상태를 표시한다.
- 결제 요청에는 idempotency key 기반 중복 방지 정책이 적용됨을 전제로 한다.

## Store 결제 진행 화면

- 결제 처리 상태를 `initiated`, `authorized`, `captured` 기준으로 표시한다.
- 지연 시 사용자에게 처리 중임을 명확히 안내한다. (최대 대기 시간: **30초**)
- 30초 타임아웃 도달 시 실패 상태로 전환하고 재시도 동선을 제공한다.

## Store 결제 실패 안내 화면

- 실패 시 결제 실패 코드와 안내 문구를 함께 노출한다.
- `failed_timeout` 발생 시 네트워크/수단 확인 후 재시도 안내를 제공한다.
- 중복 결제 우려를 줄이기 위해 마지막 결제 시도 결과 조회 링크를 제공한다.

## 취소/환불 연계 안내

- 주문 취소 시 결제 취소/환불이 연결되는 정책을 사용자에게 안내한다.
- 환불 진행 상태는 주문 상세와 결제 상세에서 일관되게 확인 가능해야 한다.
