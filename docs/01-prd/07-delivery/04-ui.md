# Delivery UI

## 대상 화면

- Store 배송 상태 확인 화면
- Admin 배차 관리 화면

## Store 배송 상태 확인

- 주문 상세에서 배송 상태 타임라인 표시
- 배송 모드, SLA 목표, 현재 진행 상태를 함께 표시
- 배차 지연/실패 시 사용자 안내 문구 표시
- 실시간 지도 추적은 MVP 범위에서 제외

## Store 상태 메시지 규칙

- 정상 진행: 준비중 -> 배차 완료 -> 배송중 -> 배송완료
- 배차 실패 1회: 자동 재시도 안내
- 2회 연속 실패: 운영 처리 중 안내

## Admin 배차 관리 화면

- 미배차/재배차 대상 목록 제공
- 배차 시도 횟수와 현재 배차 상태 표시
- 자동 재시도 이후 실패 건에 수동 재배차 액션 제공
- SLA 위반 위험 배송 필터 제공

## SLA 표시 규칙

- SLA 목표 시각과 남은 시간을 함께 표시
- 잔여 시간 10분 이하: 경고 색상(주황)
- SLA 초과: 위반 색상(빨강) + 초과 시간 표시

## 접근 제어

- Store 화면은 주문 소유 사용자만 접근 가능
- Admin 배차 화면은 운영자 권한 사용자만 접근 가능
