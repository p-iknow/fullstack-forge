# Delivery UI

## 대상 화면

| 화면                      | 대상 사용자 | 앱    |
| ------------------------- | ----------- | ----- |
| 배송 상태 확인 (타임라인) | 고객        | Store |
| 배차 관리 목록            | 운영자      | Admin |

## Store — 배송 상태 확인

### 정보 계층

- 주문 상세 화면 내 배송 상태 타임라인 섹션
- 표시 항목: 배송 모드, 현재 상태, SLA 목표 시각, 잔여 시간

### 상태-표시 매핑

| DeliveryStatus | 표시 문구   | 아이콘/색상 |
| -------------- | ----------- | ----------- |
| `pending`      | 배송 준비중 | 기본(회색)  |
| `dispatched`   | 배차 완료   | 진행(파랑)  |
| `in_transit`   | 배송중      | 진행(파랑)  |
| `delivered`    | 배송 완료   | 완료(초록)  |
| `failed`       | 배송 지연   | 경고(주황)  |
| `cancelled`    | 배송 취소   | 취소(회색)  |

### 배차 실패 시 사용자 안내

| 상황          | 안내 문구                                          |
| ------------- | -------------------------------------------------- |
| 배차 실패 1회 | "기사를 다시 배정하고 있어요. 잠시만 기다려주세요" |
| 2회 연속 실패 | "운영팀에서 처리 중이에요"                         |
| SLA 위반      | "배송이 지연되고 있어요. 죄송합니다"               |

### SLA 표시 규칙

- SLA 목표 시각과 잔여 시간을 함께 표시
- 잔여 시간 > 10분: 기본 색상
- 잔여 시간 ≤ 10분: 경고 색상(주황)
- SLA 초과: 위반 색상(빨강) + 초과 시간 표시

### 상태 갱신 방식

- **수동 새로고침** 기본 제공 (pull-to-refresh)
- 자동 폴링: 30초 간격 (배송 진행 중일 때만 활성)
- 종료 상태(`delivered`, `cancelled`) 도달 시 폴링 중단

### 빈 상태

- 주문에 배송 레코드가 없는 경우: "배송 정보를 준비 중이에요" 표시

### 에러 상태

- API 호출 실패: "배송 정보를 불러올 수 없어요. 다시 시도해주세요" + 재시도 버튼
- 네트워크 오류: 마지막 성공 데이터 유지 + 오프라인 배너

### 로딩 상태

- 초기 로딩: 타임라인 스켈레톤 UI
- 갱신 중: 기존 데이터 유지 + 미세 로딩 인디케이터

### 접근 제어

- 주문 소유 사용자만 접근 가능

## Admin — 배차 관리 화면

### 정보 계층

- 배차 대상 목록 (테이블)
- 개별 배송 상세 + 액션

### 목록 표시 항목

- 배송 ID, 주문 ID, 배송 모드, 배송 상태, 배차 상태
- 배차 시도 횟수, SLA 목표 시각, 잔여 시간, 운영자 개입 필요 여부

### 필터

- 배송 상태 (복수 선택)
- 배차 상태 (복수 선택)
- SLA 위험도: 전체 / 위험(잔여 10분 이하) / 위반(SLA 초과)
- 배송 모드: 전체 / 즉시 / 예약

### 정렬

- 기본: SLA 목표 시각 오름차순 (임박순)
- 선택 가능: 생성 시각, 배차 시도 횟수

### 페이지네이션

- cursor 기반, 페이지당 20건

### 액션

- **수동 배차**: `dispatch_state`가 `unassigned` 또는 `manual_required`인 건에 활성화
- **수동 재배차**: `dispatch_state`가 `manual_required`인 건에 활성화
- **배송 취소**: `status`가 `pending`, `dispatched`, `failed`인 건에 활성화
- 파괴적 액션(취소)은 확인 다이얼로그 필수: "배송을 취소하시겠습니까? 이 작업은 되돌릴 수 없습니다."

### 빈 상태

- 필터 결과 없음: "조건에 맞는 배송이 없습니다"
- 전체 목록 비어있음: "배송 데이터가 없습니다"

### 에러 상태

- 목록 조회 실패: "목록을 불러올 수 없습니다" + 재시도 버튼
- 액션 실패: 인라인 에러 토스트 + 실패 사유 표시

### 로딩 상태

- 목록: 테이블 스켈레톤
- 액션 실행 중: 버튼 로딩 상태 + 중복 클릭 방지

### 접근 제어

- 운영자 권한 사용자만 접근 가능

### 실시간 갱신

- 실시간 지도 추적은 MVP 범위에서 제외
- Admin 목록은 30초 자동 폴링 + 수동 새로고침 버튼
