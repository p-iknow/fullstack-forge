# Promotion UI

## 범위

프로모션 도메인의 Store/Admin UI 요구사항을 정의한다.

## Store: 쿠폰 입력/적용 UI

- 주문 시점에 활성 프로모션 후보 조회(기간/상태 필터) 결과를 사용자에게 표시
- 쿠폰 코드 입력 시 코드 유효성 검증(존재/만료/사용량/사용자별 제한) 결과를 즉시 피드백
- 최소주문금액 조건 검증 결과를 적용 가능/불가 상태로 안내
- 만료 쿠폰은 조회는 가능하나 적용 불가 상태로 표시

## Store: 할인 비교 표시

- 카테고리 할인 후보 계산(주문 아이템 카테고리 기반) 결과와 쿠폰 할인 후보를 함께 비교 표시
- 쿠폰과 카테고리 할인은 동시 적용 불가(초기)
- 사용자에게 더 유리한 할인 자동 선택
- 동일 할인액이면 쿠폰 우선(사용자 체감 일관성)
- 선택 근거(`best_price_policy`, `coupon_priority_on_tie`)를 사용자 화면과 주문 이력에 일관되게 반영

## Admin: 프로모션 관리

- 할인 정책 본체(타입/할인값/유효기간/활성상태) 관리
- 코드 기반 프로모션 세부(코드/사용 한도/유효기간) 관리
- 카테고리 할인 대상 범위 관리
- 운영자 수동 비활성화, 정책 변경 이력 관리
- 쿠폰 적용 성공/실패 감사 로그 조회
