# Order UI

## 대상 화면

- Store: 주문 목록, 주문 생성, 주문 상세(조회/취소), 대체 승인
- Admin: 주문 관리 목록, 주문 상세/상태 전이

## Store 주문 목록 화면

- 본인 주문 최신순 목록 표시
- 각 항목: 주문 번호, 주문 상태, 아이템 요약(대표 상품명 + 외 N건), 주문 금액, 주문 일시
- 상태별 필터 (전체 / 진행중 / 완료 / 취소)
- 무한 스크롤 (cursor 기반 페이지네이션)
- 항목 클릭 시 주문 상세 화면으로 이동
- **빈 상태**: "주문 내역이 없습니다" + 상품 탐색 유도 버튼
- **에러 상태**: "주문 내역을 불러오지 못했습니다. 다시 시도해주세요" + 재시도 버튼
- **로딩 상태**: 스켈레톤 UI (리스트 아이템 3~5개)

## Store 주문 생성 화면

- 장바구니 기준 주문 생성 액션 제공
- 배송 주소 입력/선택 UI (수령인 이름, 연락처 포함)
- 프로모션/쿠폰 코드 입력 영역
- 포인트 사용 입력 영역 (보유 잔액 표시, 최소 1,000원)
- 주문 금액 요약 (소계, 할인, 포인트 사용, 최종 결제 금액)
- 부분 품절 발생 시 대체 제안 또는 부분 취소 안내 표시
- 대체 상품이 더 비싼 경우 사용자 승인 UI 제공
- **에러 상태**:
  - 재고 부족: "일부 상품의 재고가 부족합니다" + 품절 아이템 강조
  - 결제 실패: "결제에 실패했습니다. 결제 수단을 확인해주세요" + 재시도 버튼
  - 최소주문금액 미달: "최소 주문 금액은 15,000원입니다" + 현재 금액 표시
  - 포인트 부족: "사용 가능한 포인트가 부족합니다"
- **로딩 상태**: 주문 생성 중 "주문 처리 중..." 전체 화면 로딩 (중복 클릭 방지)

### 대체 승인 UI 흐름

- 대체 승인 대기 상태에서 남은 시간 카운트다운(`10분`) 표시
- 원상품과 대체 상품 비교 정보 (이름, 가격, 이미지) 나란히 표시
- 가격 차이 금액 명시 (+X원 추가 또는 -X원 절약)
- 사용자 액션 버튼 `승인`/`거절`을 동일 화면에서 제공
- `승인` 클릭 시 **확인 다이얼로그**: "대체 상품으로 변경하시겠습니까? 추가 금액: +X원"
- `승인` 확인 후 대체 적용 결과와 갱신된 주문 금액을 즉시 반영
- `거절` 클릭 시 해당 아이템 부분 취소 안내와 금액 변경 내역 표시
- 제한 시간 만료 시 "응답 시간 초과로 부분 취소됨" 안내 문구를 고정 노출
- **에러 상태**: "대체 상품 처리에 실패했습니다" + 재시도 버튼
- **로딩 상태**: 승인/거절 처리 중 버튼 비활성화 + 스피너

## Store 주문 상세 화면

- 주문 상태 타임라인 표시 (`created`부터 최종 상태까지, 각 전이 시각 포함)
- 아이템 단위 상태와 대체 적용 결과 표시
- 부분 실패/부분 품절 발생 아이템 강조 표시 (배지 또는 색상 구분)
- 주문 금액 상세 (소계, 할인, 포인트 사용, 최종 결제 금액)
- 배송 정보 (주소, 수령인, 배송 상태)
- **에러 상태**: "주문 정보를 불러오지 못했습니다" + 재시도 버튼
- **로딩 상태**: 스켈레톤 UI (헤더 + 아이템 리스트 + 금액 요약)

## Store 주문 취소 화면

- 취소 가능한 상태(`created`)에서만 취소 액션 노출
- 취소 버튼 클릭 시 **확인 다이얼로그** 표시:
  - "주문을 취소하시겠습니까?"
  - 취소 시 연쇄 효과 안내:
    - 환불 예정 금액
    - 포인트 복원 예정량
- 취소 사유 선택 (선택 목록: 단순 변심, 배송 지연 예상, 상품 변경 희망, 기타)
- 취소 처리 중 로딩 상태 표시 (버튼 비활성화 + 스피너)
- 취소 완료 후 환불 예정 정보 표시
  - 결제 환불 예정 금액
  - 포인트 복원 예정량
  - 환불 소요 예상 시간 안내
- **에러 상태**: "주문 취소에 실패했습니다. 다시 시도해주세요" + 재시도 버튼

## Admin 주문 관리 목록 화면

- 전체 주문 목록 (테이블 형태)
- 컬럼: 주문 번호, 고객명, 주문 상태, 주문 금액, 주문 일시
- 상태별 필터 (전체 + 각 상태)
- 날짜 범위 필터
- 주문 번호/고객명 검색
- 페이지네이션 (페이지 번호 방식)
- 행 클릭 시 주문 상세/상태 전이 화면으로 이동
- **빈 상태**: "조건에 맞는 주문이 없습니다"
- **에러 상태**: "주문 목록을 불러오지 못했습니다" + 재시도 버튼
- **로딩 상태**: 테이블 스켈레톤

## Admin 주문 상태 전이 화면

- 현재 상태와 허용 다음 상태를 함께 표시
- 불법 전이 선택지는 UI에서 비활성화
- 전이 실행 시 **확인 다이얼로그**: "주문 상태를 [현재] → [대상]으로 변경하시겠습니까?"
- 취소 전이 시 사유 입력 필수 (텍스트 영역)
- 상태 전이 실행 시 감사 로그 대상 정보 표시 (변경자, 변경 시각, 사유)
- 상태 변경 이력 타임라인 표시 (OrderStatusHistory 기반)
- Stage 6 운영 목표에 맞춰 상태 전이/redrive 진입 경로 제공
- **에러 상태**:
  - 낙관적 락 충돌: "다른 운영자가 이미 상태를 변경했습니다. 새로고침해주세요"
  - 불법 전이: "현재 상태에서 해당 전이는 불가합니다"
- **로딩 상태**: 전이 처리 중 버튼 비활성화 + 스피너

## 접근 제어

- Store 화면은 주문 소유 사용자만 접근 가능
- Admin 화면은 운영자 권한 사용자만 접근 가능
- 권한 없는 접근 시 403 안내 페이지 표시
