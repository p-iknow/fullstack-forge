# Order UI

## 대상 화면

- Store 주문 생성/조회/취소 화면
- Admin 주문 상태 전이 화면

## Store 주문 생성 화면

- 장바구니 기준 주문 생성 액션 제공
- 부분 품절 발생 시 대체 제안 또는 부분 취소 안내 표시
- 대체 상품이 더 비싼 경우 사용자 승인 UI 제공

### 대체 승인 UI 흐름

- 대체 승인 대기 상태에서 남은 시간 카운트다운(`10분`) 표시
- 사용자 액션 버튼 `승인`/`거절`을 동일 화면에서 제공
- `승인` 클릭 시 대체 적용 결과와 갱신된 주문 상태를 즉시 반영
- `거절` 클릭 시 해당 아이템 부분 취소 안내와 금액 변경 내역 표시
- 제한 시간 만료 시 `응답 시간 초과로 부분 취소됨` 안내 문구를 고정 노출

## Store 주문 조회 화면

- 주문 상태 타임라인 표시(`created`부터 최종 상태까지)
- 아이템 단위 상태와 대체 적용 결과 표시
- 부분 실패/부분 품절 발생 아이템 강조 표시

## Store 주문 취소 화면

- 취소 가능한 상태에서만 취소 액션 노출
- 취소 시 연쇄 효과 안내
  - inventory 복원
  - payment 환불
  - loyalty 롤백
  - delivery 취소
  - notification 알림

## Admin 주문 상태 전이 화면

- 현재 상태와 허용 다음 상태를 함께 표시
- 불법 전이 선택지는 UI에서 비활성화
- 상태 전이 실행 시 감사 로그 대상 정보 표시
- Stage 6 운영 목표에 맞춰 상태 전이/redrive 진입 경로 제공

## 접근 제어

- Store 화면은 주문 소유 사용자만 접근 가능
- Admin 상태 전이 화면은 운영자 권한 사용자만 접근 가능
