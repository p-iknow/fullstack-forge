# Inventory UI

## 대상 화면

관리자(Admin) 재고 모니터링 화면을 정의한다.

## 핵심 목표

- SKU 단위 재고 상태를 빠르게 파악
- 저재고/품절을 우선 식별
- 수동 조정 액션의 안전한 실행

## 화면 목록

| 화면                 | 경로               | 설명                             |
| -------------------- | ------------------ | -------------------------------- |
| 재고 관리            | `/admin/inventory` | 목록 + 상세 패널 (마스터-디테일) |
| 재고 조정 다이얼로그 | 모달               | 수동 조정 입력 + 확인            |

## 화면 구성

- 상단 요약 카드
  - 전체 SKU 수
  - 저재고 SKU 수
  - 품절 SKU 수
- 재고 목록 테이블
  - 컬럼: 상품명, SKU, `on_hand`, `reserved`, `available`, 상태 배지
  - 상태 배지(`normal`, `low_stock`, `out_of_stock`)
  - 기본 정렬: `available` 오름차순 (재고 부족 SKU 우선)
  - 검색: 상품명/SKU 텍스트 검색
  - 필터: 상태별 (`low_stock`, `out_of_stock`)
- 우측 상세 패널
  - 선택 SKU의 재고 수량 상세
  - 최근 조정 이력 목록 (InventoryAdjustmentLog 기반, 최근 10건)
  - 수동 조정 진입 버튼

## 저재고 알림 표시

- 저재고 기준: `available < safety_threshold` (임계치 정의는 [01-overview.md § 안전재고 임계치](./01-overview.md#안전재고-임계치) 참조)
- 저재고 임계치 미만인 SKU는 목록 상단 고정 옵션 제공
- `low_stock` 배지와 경고 아이콘을 함께 표시
- 품절 SKU는 별도 강조 색상으로 구분

## 빈 상태 (Empty State)

- **재고 데이터 없음** (초기 상태): "등록된 상품이 없습니다. 카탈로그에서 상품을 먼저 등록하세요." 메시지와 카탈로그 관리 페이지 링크를 표시한다.
- **필터 결과 없음**: "조건에 맞는 재고가 없습니다." 메시지를 표시하고 필터 초기화 버튼을 제공한다.
- **상세 패널 미선택**: 목록에서 SKU를 선택하라는 안내 텍스트를 표시한다.

## 로딩 상태

- 목록 초기 로딩: 테이블 영역에 스켈레톤 UI를 표시한다.
- 상세 패널 로딩: 패널 내부에 스피너를 표시한다.
- 조정 요청 처리 중: 확인 버튼을 비활성화하고 스피너를 표시한다.

## 에러 상태

- API 호출 실패: 인라인 에러 메시지와 재시도 버튼을 표시한다.
- 버전 충돌(409): "다른 운영자가 재고를 수정했습니다. 최신 데이터를 확인하세요." 메시지와 새로고침 버튼을 표시한다.
- 재고 부족/음수 결과: 조정 다이얼로그 내에서 인라인 validation 에러를 표시한다.

## 데이터 갱신

- 기본: 수동 새로고침 (목록 상단 새로고침 버튼)
- 조정 완료 후: 해당 SKU의 데이터를 자동 재조회하여 목록과 상세 패널을 갱신한다.
- 자동 갱신(polling)은 MVP에서 제외. 향후 WebSocket 기반 실시간 갱신을 검토한다.

## 상호작용 규칙

- 조정 액션 전 확인 다이얼로그 필수 (조정 수량, 사유 입력 → "조정하시겠습니까?" 확인)
- 충돌(버전 불일치) 발생 시 최신 값 재조회 안내
- 음수 결과가 되는 입력은 클라이언트에서 사전 차단 (delta 입력 시 결과 미리보기 제공)
- 정렬 변경: 컬럼 헤더 클릭으로 토글 (`available` asc/desc, `on_hand` desc, 상품명 asc)

## 벌크 액션

- MVP에서는 벌크 조정을 지원하지 않는다. 단건 조정만 제공.
- 향후 다수 SKU 일괄 입고를 위한 CSV 업로드 + 벌크 조정을 검토한다.

## 접근 제어

- 관리자 권한 사용자만 진입 가능
- 스토어 사용자 화면에는 해당 관리 UI를 노출하지 않음

## 반응형

- 데스크톱 우선 설계 (admin은 데스크톱 사용 전제)
- 최소 해상도: 1280×720
- 상세 패널은 1280px 미만에서 하단 슬라이드 패널로 전환
