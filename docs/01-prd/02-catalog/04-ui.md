# Catalog UI Requirements

## 1) store 상품 목록 화면

- 카테고리, 브랜드, 상태 기준으로 상품을 탐색할 수 있어야 한다.
- 상품 카드에서 이름, 브랜드, 가격, 재고 표시 상태, 썸네일을 노출한다.
- `out_of_stock` 상품은 목록에서 명확하게 품절 배지를 표시한다 (재고 수량에서 계산).

## 2) store 상품 상세 화면

- 상품 기본 정보(이름, 브랜드, 가격, 중량, 재고 표시 상태)를 노출한다.
- 대표 이미지(`thumb_url`)와 상세 이미지(`detail_url`)를 노출한다.
- `out_of_stock`에서는 구매 불가 상태를 명확하게 표시한다.

## 3) store 검색 화면

- 검색어 입력으로 상품을 조회할 수 있어야 한다.
- 카테고리/상태/브랜드 필터를 함께 적용할 수 있어야 한다.
- 검색 결과에서도 품절 상태를 일관되게 표시한다.

## 4) admin 상품 관리 화면

### 상품 목록

- 상품 목록 조회, 검색, 필터링을 지원한다.
- 상품 활성 여부(`is_active`)와 재고 표시 상태(`in_stock`/`low_stock`/`out_of_stock`)를 확인할 수 있어야 한다.
- 카테고리별 상품 분류 현황을 확인할 수 있어야 한다.
- 각 상품 행에서 수정/삭제 액션을 제공한다.
- 상품 등록 버튼으로 생성 폼으로 이동할 수 있다.

### 상품 등록/수정 폼

- 상품명, 설명, 가격, 카테고리, 대체 가능 여부를 입력할 수 있다.
- 카테고리는 드롭다운으로 선택한다 (API에서 목록 조회).
- 폼 입력값은 클라이언트 측 유효성 검증을 수행한다 (Zod).

### 이미지 업로드

- 상품 등록/수정 시 썸네일(thumb)과 상세 이미지(detail)를 업로드할 수 있다.
- 파일 선택 또는 드래그앤드롭으로 이미지를 선택한다.
- 업로드 전 이미지 미리보기를 제공한다.
- 수정 시 현재 이미지를 표시하고 새 파일로 교체할 수 있다.
- 허용 포맷: JPEG, PNG, WebP / 최대 5MB.

### 상품 활성 관리

- 목록에서 상품을 활성/비활성 전환할 수 있다 (`is_active` 토글).
- 재고 표시 상태(`in_stock`/`low_stock`/`out_of_stock`)는 재고 수량에서 자동 계산되므로 수동 변경 대상이 아니다.
- 비활성화 전 확인을 요청한다.

### 상품 삭제

- 삭제 전 확인 다이얼로그를 표시한다.
- 주문 이력이 있는 상품은 삭제 불가 메시지를 표시한다.

## 5) admin 카테고리 관리 화면

- 카테고리 목록 조회, 생성, 수정, 삭제를 지원한다.
- 카테고리명, slug, 표시 순서, 활성 여부를 편집할 수 있다.
- 상품이 존재하는 카테고리는 삭제 불가 메시지를 표시한다.

## 6) 재고/품절 표시 정책

- `in_stock`: 기본 상태. 별도 배지 없이 구매 가능으로 표시한다.
- `low_stock`: 재고 부족 배지를 표시한다 (조회 시 `available > 0 && available <= safety_threshold(5)`로 계산).
- `out_of_stock`: 품절 배지와 함께 구매 불가 상태로 표시한다 (조회 시 `available == 0`으로 계산).
- `is_active = false`: 비활성(단종) 상태로 표시하고 주문 이력 조회 맥락에서만 노출한다.
- 재고/품절 표시는 목록/상세/검색 화면에서 동일한 기준으로 유지한다.
- 판매 가능 여부 판정 기준은 `01-overview.md §4`를 따른다.
