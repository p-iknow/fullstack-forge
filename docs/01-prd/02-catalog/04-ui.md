# Catalog UI Requirements

## 1) store 상품 목록 화면

- 카테고리, 브랜드, 상태 기준으로 상품을 탐색할 수 있어야 한다.
- 상품 카드에서 이름, 브랜드, 가격, 상태, 썸네일을 노출한다.
- out_of_stock 상품은 목록에서 명확하게 품절 상태를 표시한다.

## 2) store 상품 상세 화면

- 상품 기본 정보(이름, 브랜드, 가격, 중량, 상태)를 노출한다.
- 대표 이미지(`thumb_url`)와 상세 이미지(`detail_url`)를 노출한다.
- 품절 상태(out_of_stock)에서는 구매 불가 상태를 명확하게 표시한다.

## 3) store 검색 화면

- 검색어 입력으로 상품을 조회할 수 있어야 한다.
- 카테고리/상태/브랜드 필터를 함께 적용할 수 있어야 한다.
- 검색 결과에서도 품절 상태를 일관되게 표시한다.

## 4) admin 상품 관리 화면

- 상품 목록 조회, 검색, 필터링을 지원한다.
- 상품 상태(active/low_stock/out_of_stock/discontinued)를 확인할 수 있어야 한다.
- 카테고리별 상품 분류 현황을 확인할 수 있어야 한다.

## 5) 품절 표시 정책

- `out_of_stock`: 품절 배지와 함께 구매 불가 상태로 표시한다.
- `discontinued`: 신규 구매 불가 상태로 표시하고 주문 이력 조회 맥락에서만 노출한다.
- 품절 표시는 목록/상세/검색 화면에서 동일한 기준으로 유지한다.
- 판매 가능 여부 판정 기준은 `01-overview.md §4`를 따른다.
