# Notification Domain UI Requirements

## 문서 상태

- 본 문서는 **기존 PRD(01~05)에 미포함된 알림 도메인을 신규 정의**하기 위해 작성되었다.
- MVP UI 범위는 store 앱의 사용자 알림 화면이며 admin 알림 화면은 포함하지 않는다.

## 대상 사용자

- store 고객 (로그인 사용자)

## 화면 인벤토리

| 화면/컴포넌트 | 위치 | 설명 |
| --- | --- | --- |
| 알림 배지 (Badge) | 글로벌 네비게이션 바 | 미읽음 개수 표시 |
| 알림 목록 (Notification List) | 알림 전용 페이지 | 전체 알림 타임라인 |

## 알림 배지 (Global Navigation)

- 위치: 글로벌 네비게이션 바의 알림 아이콘 옆
- 미읽음 개수 표시:
  - `0`건: 배지 숨김
  - `1~99`건: 숫자 표시
  - `100`건 이상: `99+` 표시
- 갱신 방식: 알림 목록 진입 시 및 **60초 간격 폴링** (MVP)
  - 확장 시 SSE 또는 WebSocket으로 전환 가능
- 배지 클릭 시 알림 목록 페이지로 이동

## 알림 목록

### 정보 계층

각 알림 항목은 다음 정보를 표시한다:

| 요소 | 설명 |
| --- | --- |
| 타입 아이콘 | `type` 값에 따른 아이콘 (주문/배송/결제/리뷰/포인트/문의/장바구니/할인) |
| 제목 (`title`) | 알림의 핵심 내용 (최대 100자, 1줄 표시) |
| 본문 요약 (`body`) | 상세 문맥 (최대 2줄, 말줄임 처리) |
| 생성 시각 (`created_at`) | 상대 시간 표시 (예: 5분 전, 2시간 전, 3일 전) |
| 미읽음 표시 | 미읽음 항목에 강조 배경색 또는 좌측 인디케이터 |

### 정렬

- 기본 정렬: 최신 생성 시각 우선 (`created_at DESC`)
- 다른 정렬 옵션 없음 (MVP)

### 필터

- 전체 / 읽음 / 미읽음 탭 전환 제공
- 기본 선택: 전체

### 페이지네이션

- 방식: **무한 스크롤** (커서 기반)
- 초기 로드: **20건**
- 추가 로드: 스크롤 하단 도달 시 20건씩 추가 요청
- 끝 도달 시: "더 이상 알림이 없습니다" 안내 표시

## 상호작용 정책

### 단건 읽음 처리

- 알림 항목 클릭 시:
  1. 미읽음 → 읽음 상태 전환 (API 호출)
  2. `link_target` 경로로 화면 이동 (관련 주문/배송/리뷰 등)
- 이미 읽음인 항목 클릭 시: 읽음 처리 재요청 없이 화면 이동만

### 다건 읽음 처리

- "모두 읽음" 버튼 제공 (현재 사용자의 전체 미읽음 알림 일괄 처리)
- 확인 다이얼로그 없이 즉시 처리 (비가역이나 데이터 손실 아님)
- 처리 완료 후 목록 상태 즉시 반영

## 상태별 화면 처리

### 로딩 상태

- 초기 로드: 알림 항목 형태의 skeleton UI 표시 (3~4줄)
- 추가 로드 (무한 스크롤): 하단에 spinner 표시
- 읽음 처리 중: 해당 항목 opacity 감소 (처리 완료 시 복원)

### 빈 상태

- 안내 문구: "아직 알림이 없습니다"
- 복귀 동선: 메인 페이지로 이동 버튼 제공

### 오류 상태

- 목록 조회 실패: "알림을 불러오지 못했습니다" + 재시도 버튼
- 읽음 처리 실패: 토스트 메시지로 "읽음 처리에 실패했습니다. 다시 시도해주세요" 표시, 상태 롤백

## 비범위

- admin 알림 센터 UI
- 운영 이벤트(장애, 지연, 큐 적체) 노출 UI
  - 해당 영역은 `../14-observability/01-overview.md`에서 별도 관리
- push/email/SMS 설정 화면의 상세 워크플로
- 알림 삭제 UI (MVP에서 사용자 삭제 미지원)

## 이벤트 도메인 연결

- 화면에 보이는 데이터는 notifications 큐 소비 결과로 생성된 알림 레코드이다.
- 이벤트 envelope 및 소비 규약은 `../13-event/01-overview.md`를 참조한다.
- fanout 및 신뢰성 운영 기준은 `../13-event/01-overview.md`를 따른다.
