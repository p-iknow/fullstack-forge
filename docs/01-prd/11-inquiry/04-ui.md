# Inquiry UI

## 대상 화면

- Store 문의 생성/목록/조회 화면
- Admin 문의 inbox/상세/답변/상태 전이 화면

## 공통 UX 기준

- 문의 상세 화면에 상태(`open/in_progress/resolved/closed`)와 최근 답변 시간 표시
- `closed` 상태의 문의는 재오픈 불가 안내 및 새 문의 생성 링크를 표시
- 재오픈 횟수가 3회에 도달한 `resolved` 문의도 재오픈 불가 안내 표시

## Store 문의 생성 화면

- `POST /inquiries` 진입 경로 제공
- **문의 제목** 입력 (최대 200자, 잔여 글자수 표시)
- **문의 카테고리** 선택 (`order|payment|delivery|product|account|other`)
- 카테고리가 `order|payment|delivery`인 경우 **관련 주문 선택** UI 표시 (최근 주문 목록에서 선택, 선택 안 함 허용)
- **문의 본문** 입력 (최대 5,000자, 잔여 글자수 표시)
- 생성 완료 후 문의 상세 화면으로 이동
- **로딩 상태**: 생성 요청 중 버튼 비활성화 + 스피너
- **에러 상태**: Rate limit 초과 시 "잠시 후 다시 시도해주세요" 안내, 서버 오류 시 재시도 안내

## Store 문의 목록 화면

- `GET /inquiries`로 내 문의 목록 조회
- 상태별 필터(`open|in_progress|resolved|closed`) 제공
- 기본 정렬: 최신 생성순
- 각 문의 항목에 제목, 카테고리, 상태, 생성 시각, 최근 답변 시각 표시
- **Empty 상태**: 문의가 없을 때 "아직 문의가 없습니다" 안내 + 문의 생성 버튼
- **로딩 상태**: 목록 로딩 중 스켈레톤 UI
- **에러 상태**: API 실패 시 "문의 목록을 불러올 수 없습니다" + 재시도 버튼
- 커서 기반 페이지네이션: 스크롤 하단 도달 시 다음 페이지 로드

## Store 문의 상세 화면

- `GET /inquiries/{id}` 기반으로 문의 제목/본문/답변/상태 표시
- 카테고리 및 관련 주문 정보 표시 (주문 연결 시 주문 상세 링크)
- 최근 답변 시간 표시
- 답변 목록: 시간순 정렬, 운영자/고객 구분 표시 (`is_internal=true` 답변은 미노출)
- 본인 문의만 조회 가능하도록 접근 제어
- `resolved` 상태에서 추가 질문 입력 시 재오픈 진행 (`POST /inquiries/{id}/reopen`)
  - 재오픈 횟수 잔여 표시 (예: "추가 질문 가능 2회 남음")
  - 재오픈 횟수 초과 시 입력 비활성화 + "새 문의를 작성해주세요" 안내
- **로딩 상태**: 상세 로딩 중 스켈레톤 UI
- **에러 상태**: 404 시 "문의를 찾을 수 없습니다" 안내, 403 시 "접근 권한이 없습니다" 안내

## Admin 문의 inbox 화면

- `GET /admin/inquiries` 기반
- **필터**:
  - 상태 필터 (`open|in_progress|resolved|closed`)
  - 카테고리 필터 (`order|payment|delivery|product|account|other`)
  - 담당자 필터 (미할당/내 문의/전체)
  - SLA 상태 필터 (`normal|warning|violated`)
- **키워드 검색**: 문의 제목/본문 검색
- **SLA 우선순위 표시**:
  - 정상: 기본 표시
  - 주의 (12시간 경과): 노란색 경고 배지
  - 위반 (24시간 초과): 빨간색 위반 배지
- **정렬**: 생성 시각 최신순 (기본), SLA 긴급도순 전환 가능
- **대량 처리**:
  - 체크박스로 다건 선택
  - 일괄 상태 전이 (선택한 문의를 한 번에 closed 처리)
  - 일괄 담당자 할당
  - 확인 다이얼로그: "선택한 N건의 문의를 종결 처리하시겠습니까?"
- 각 문의 항목에 제목, 카테고리, 상태, 고객명, 담당자, 생성 시각, SLA 상태 표시
- **Empty 상태**: 필터 결과 없을 때 "조건에 맞는 문의가 없습니다" 안내
- **로딩 상태**: 목록 로딩 중 스켈레톤 UI
- **에러 상태**: API 실패 시 "문의 목록을 불러올 수 없습니다" + 재시도 버튼
- 커서 기반 페이지네이션

## Admin 문의 상세/답변 화면

- 문의 전체 정보: 제목, 카테고리, 상태, 고객 정보, 관련 주문 (주문 상세 링크), SLA 상태
- `POST /inquiries/{id}/replies` 답변 작성
  - 공개 답변 / 내부 메모 전환 토글 (`is_internal` 제어)
  - 답변 본문 길이 표시 (최대 10,000자)
- `PATCH /inquiries/{id}` 상태 전이 수행
  - 허용 상태 전이(`open -> in_progress -> resolved -> closed`)만 선택 가능
  - 비활성 전이 옵션은 회색 처리 + 사유 tooltip
- `PATCH /admin/inquiries/{id}/assign` 담당자 할당/변경
- **확인 다이얼로그**:
  - 상태 전이 시: "문의를 [상태]로 변경하시겠습니까?"
  - `closed` 전이 시: "종결 후 재오픈이 불가합니다. 종결하시겠습니까?"
- 답변 이력: 시간순 정렬, 공개/내부 구분 표시, 작성자 역할 표시
- **로딩 상태**: 답변 등록/상태 전이 중 버튼 비활성화 + 스피너
- **에러 상태**: 409 충돌 시 "다른 운영자가 먼저 변경했습니다. 새로고침 후 다시 시도해주세요" 안내
